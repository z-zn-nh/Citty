# 可本地部署的模型清单（按阶段，体积全部实测）

> 2026-10-06。**所有 GB 数都是从 HF / ModelScope 的文件接口读出来的真实字节数**（不是参数量换算）。
> 标 ✅ 的是**已核实**；标 ⚠️ 的是**接口返回 401/404 拿不到**，只给量级。
> **本文只是清单，一个文件都没下**（所有缓存目录仍然不存在）。
> 显存换算规则：**显存 ≈ 权重文件 + 1~3GB**（上下文/KV/激活/框架开销）。
> 仓库"合计"常把同一权重的多种格式各算一份（fp32 + tf + rust + onnx），所以我会同时给**实际要加载的那个文件**。

## 按机器档位筛选：8 核 / 15 GB 内存 / 39 GB 磁盘 / **无 GPU** 的云工作区

这类机器（典型是"云端工作环境"而不是 VPS）的**真正约束是 15GB 内存**，不是磁盘也不是算力。
没有 NVIDIA 显卡意味着：**不能跑 vLLM、不能用 CUDA 版 torch、不能用 bf16/flash-attn**，
所有模型只能走 **llama.cpp / onnxruntime / CTranslate2 的 CPU 路径**。

### 三档可落地组合（磁盘 39GB 完全够，占的是内存）

| 组合 | 内容 | 磁盘 | 常驻内存 |
|---|---|---|---|
| **① P1 实时字幕（推荐先做）** | SenseVoice ONNX + Hy-MT2-1.8B | **1.59 GB** | ≈ 2.1 / 15 GB |
| ② 全部 CPU 能力 | ① + Fun-ASR-Nano + whisper-turbo + Index-Translate-2B + Kokoro + demucs + 2B 决策 | 7.01 GB | ≈ 8 GB |
| ③ 再加音色克隆 | ② + CosyVoice2（仅离线跑） | 11.53 GB | ≈ 8 GB（分时） |
| ④ 再加 7B 翻译（离线） | ③ + Hy-MT2-7B Q4 | 15.84 GB | ≈ 12.8 GB ← **贴着 15GB 上限** |

**结论**：这台机器干 **P1 实时字幕 + P2 影子配音 + P3 路由 + P4 多语种翻译** 毫无压力；
**P2 的"音色克隆配音"只能离线跑**；**P3 的 JEV-9B 放不下**（用 2B 决策模型或免费 API 替代）。

### 速度预期（重要：别拿别人的机器当自己的）

我实测那台是 **i7-12850HX（55W HX，单核很强，16C/24T）**，SenseVoice int8 在 8 线程上 5 秒片段 **110ms（RTF 0.022）**。
云上 8 vCPU（往往是共享/较老架构）单核更弱，**预期慢 1.5~3 倍**：
- SenseVoice：RTF 大概 **0.05~0.15** → **仍然是实时**（5 秒音频 0.25~0.75 秒出结果）
- Hy-MT2-1.8B Q4（llama.cpp，8 线程）：大概 **20~40 token/s** → 一句字幕 1~2 秒
- `num_threads` 建议 **6~8**（留一两个核给采集/ffmpeg/VAD，别全占满）

> 顺带一个巧合：我在 [10](10-免费方案与最小部署.md) 里给 P1 的"最小自建档"是 **2C4G 无 GPU**，
> 这台 8C/15G 是它的 4 倍资源和 7 倍内存——**对 P1 来说绰绰有余**。

## 运行方式对照（同一个模型，不同 runner）

| Runner | 吃哪些模型 | 一句话 |
|---|---|---|
| **llama.cpp / llama-server** | 所有 GGUF（SenseVoice/Fun-ASR-Nano/Hy-MT2/Index-Translate/Qwen 系/2B 决策） | **最省资源**，`-ngl` 决定上多少层到 GPU；`llama-server` 直接给 OpenAI 兼容 HTTP |
| **funasr / ModelScope** | SenseVoice、Paraformer、fsmn-vad、ct-punc | 中文 ASR 全家桶，`AutoModel` 一行加载 |
| **faster-whisper** | Whisper 系（CT2 格式） | 比原版快 4 倍、int8 省显存 |
| **sherpa-onnx / onnxruntime** | ONNX 版 SenseVoice、VAD、Piper、Kokoro | **CPU 实时专用** |
| **vLLM** | Qwen3-ASR、JEV-9B、Qwen 系 | 高吞吐；**T4/V100 上要显式 `dtype=float16`**（见 [11](11-Kaggle与AIStudio评估.md)） |
| **transformers** | NLLB / m2m100 / opus-mt / ChatTTS / MOSS-TTSD | 万能但慢，适合离线 |
| **demucs / pyannote** | 分离与说话人 | pip 装完即用 |

## 你这台机器现在能跑什么（诚实版）

| 事实 | 影响 |
|---|---|
| `torch 2.12.0+cpu`、`cuda.is_available()==False` | **现在只能跑 CPU 那档**（A 档完全可行）；要 GPU 得换装 CUDA 版 torch（约 3GB 下载） |
| C 盘只剩 **18.8GB** | 别往 C 盘装模型；D 盘 116.9GB、E 盘 239.5GB 才是落脚点 |
| 必须改缓存路径 | `HF_HOME=E:\hf`、`MODELSCOPE_CACHE=E:\ms`，否则默认落 C 盘 |
| 显存 8GB（8188 MiB，空闲 7724） | B 档要分时跑；CosyVoice2 + demucs 同时上会紧 |
| 内存只剩 11.1GB 空闲 | 加载 7B 级模型前先关浏览器 |

**建议第一步**（仍然零下载）：先只拉 **SenseVoice-GGUF(q8 0.24GB) + Hy-MT2-1.8B-Q6(1.37GB)** = **1.6GB**，
CPU 上跑通 `citty file`，确认本地链路后再决定要不要下 4.5GB 的 TTS。
